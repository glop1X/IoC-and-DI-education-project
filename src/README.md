# Dependency Injection Practice

A small educational project created to practice the **Dependency Injection (DI)** concept in Java.

In this project, I learned the main idea behind dependency injection: an object does not create its dependencies by itself, but instead receives them from an external source.

The project includes:

* a notification interface;
* several implementations of this interface;
* a factory for creating the required implementation;
* a service that receives its dependency through the constructor.

The main goal of this project was not to build a complete application, but to better understand **Dependency Injection**, loose coupling between classes, and working with interfaces.

This project was created for educational purposes only.
